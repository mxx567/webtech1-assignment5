# Assignment 5 — JavaScript Basics

This project covers JavaScript fundamentals, DOM manipulation, and event handling through small interactive web tasks.

## Assignment tasks

- **Task 0:** Print student details in the console and show an alert.
- **Task 1:** Practice variables, data types, arithmetic, and string concatenation.
- **Task 2:** Change paragraph text with a button.
- **Task 3:** Change a container’s background color and text size.
- **Task 4:** Add and remove list items.
- **Task 5:** Change a box color on mouseover and mouseout.
- **Task 6:** Display input text in real time with a keyboard event.
- **Task 7:** Calculate addition, subtraction, multiplication, and division.
- **Task 8:** Manage a to-do list: add tasks, mark them complete, and delete them. Tasks are stored in an array and are not saved after refresh.

## Run

Open `index.html` in a browser, or visit the published GitHub Pages or Netlify site. Use the navigation bar to open each task page. No installation is required.

## Technologies

HTML, CSS, JavaScript, and Bootstrap.
